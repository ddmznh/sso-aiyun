## 📖 项目简介

**爱云科技 SSO (Single Sign-On)** 是一套功能完整、安全可靠的单点登录认证系统。它实现了“一次登录，全站通行”的核心目标，支持多种认证方式（微信扫码、账号密码、手机短信），并提供完善的管理后台和用户中心。

系统严格遵循 **OAuth2.0** 标准协议，可轻松接入多个第三方应用（如资讯站、商城、论坛等），统一管理用户身份与权限。

### ✨ 核心特性

- 🔐 **多模态认证**: 支持微信扫码、传统账号密码、手机短信验证码三种登录方式。
- 🛡️ **企业级安全**: 内置 CSRF/XSS 防护、SQL 注入防御、密码强度策略、登录失败锁定、IP 频率限制。
- 🌐 **标准协议**: 完整实现 OAuth2.0 授权码模式，提供标准 `/authorize`, `/token`, `/userinfo` 接口。
- 📊 **数据驾驶舱**: 实时展示活跃用户、登录分布、安全告警等关键指标。
- 🎨 **现代 UI**: 玻璃拟态设计风格，支持深色模式，完美适配 PC/移动端。
- 🚀 **一键部署**: 可视化安装向导，5 分钟即可完成环境检测、数据库配置和系统初始化。

## 🚀 快速开始

### 1. 环境要求
- PHP >= 8.1
- MySQL >= 5.7
- Extension: PDO, GD, OpenSSL, Curl
- Nginx/Apache (开启 Rewrite)

### 2. 一键安装 (推荐)
1. 上传源码到服务器根目录。
2. 访问 `https://您的域名/install/`。
3. 按照 5 步向导操作：
   - 同意协议
   - 环境检测 (自动通过)
   - 填写数据库信息 (自动测试连接)
   - 设置管理员账号
   - 配置微信/短信参数 (可稍后修改)
4. 安装完成，自动跳转登录页。

### 3. 手动配置 (可选)
若无法访问安装向导，可手动配置：
```bash
# 复制配置模板
cp includes/config.example.php includes/config.php

# 编辑配置文件
vim includes/config.php
# 填入 DB_HOST, DB_NAME, WX_APPID 等真实信息

# 导入数据库
mysql -u root -p sso_aiyun_top < database/init.sql

# 设置权限
chmod -R 755 /var/www/html
chmod -R 777 /var/www/html/includes # 如需写入 config
```

### 4. 配置定时任务 (可选但推荐)
清理过期数据，保持系统轻量：
```bash
crontab -e
# 每天凌晨 2 点执行清理
0 2 * * * php /path/to/your/site/cron/clean.php
```

## 📂 目录结构

```
.
├── admin/                  # 管理后台模块
├── api/                    # OAuth2.0 及业务接口
├── assets/                 # 静态资源 (CSS/JS/Images)
├── cron/                   # 定时任务脚本

├── 404.php / 500.php       # 错误页面
├── README.md               # 项目说明 (本文件)
```
